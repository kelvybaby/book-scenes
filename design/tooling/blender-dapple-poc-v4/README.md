# Blender dappled-light proof of concept — revision 4

Revision 4 abandons the stacked full-frame occlusion fields. The Blender scene
contains one connected canopy-projection mesh generated by
`scripts/blender/dapple_topology.py`.

## Hierarchy

- A dense, slow lower-left/central core represents the trunk and main canopy.
- Three branch groups emerge from the core as narrow connected webs.
- Each branch owns clustered off-axis foliage nodes, satellites, and small
  projected bridge gaps.
- Shape-key weights are spatially tied to those branch groups. A group's web and
  clusters bend together; outer vertices flutter more than the core.
- Narrow gaps can close under the same mesh deformation and later reopen. No
  brightness pulsing or separate sliding masks are used.

The complete canopy also inherits the asymmetric seamless gust transform from
revision 3, reduced in amplitude so internal topology changes carry more of the
visible motion.

## Receiver

The v4 receiver follows the full user-supplied red potential-ground outline. It
uses the registered right-foreground vegetation alpha, so plant pixels remain
excluded while shaded ground between stems remains available. Florentino, bench,
book, left vegetation, curb, and bright road remain protected.

The receiver is permissive. The connected topology occupies only part of it and
fragments before the outer boundary; the receiver edge is not the visible shadow
edge.

## Composite

The approved painting remains the temporal baseline. Positive illumination
deviations recover restrained warm light; negative deviations deepen existing
shade multiplicatively. A low-amplitude static bias gives the core extra weight.

The review values are:

- warm recovery: `0.14`
- moving shadow deepening: `0.42`
- dense core bias: `0.065`
